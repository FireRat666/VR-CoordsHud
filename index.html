Coords HUD

A Minecraft-style readout in a corner of your view: where you're standing and which way you face. Made for SideQuest / AltspaceVR worlds, in VR and on PC.

XYZ: 12.345 / 1.000 / -4.200
Facing: North-East (+X +Z)

Open coords-hud.firer.at as a space in Altspace to try it.

← All games FireR.at Ko-fi

What it shows

  • XYZ is where you're standing, in Unity world units (metres). X and Z are under your head; Y is your feet, so it stays right when you jump, fly or sit.
  • Facing is which way your head points round you (looking up or down doesn't change it): a compass name in 45 degree steps, then the world axes. Looking along an axis shows one, like East (+X); between two it shows both, like North-East (+X +Z).
  • Only you see your HUD.
  • On PC it sits in a corner of the window (top left to start with), and F3 shows and hides it. In VR, where a headset has no window edges, it sits near the edge of your view (bottom left to start with).

2a. Add it in Unity

You need a Unity project with the Altspace Creator SDK already set up, and your world's scene open.

  1. Make an empty object. In the top menu choose GameObject › Create Empty. Rename it to Coords HUD so you can find it later (the object's name doesn't matter, only the slug does). Where it is doesn't matter either: the HUD goes on each player's head.
  2. Add the Snippet component. Click Add Component, type Snippet in the search box, and pick BS › Snippet.
  3. Type the slug and press Enter. In the Snippet's Slug box type and press Enter (the box only takes it after Enter or clicking somewhere else). It downloads the snippet and adds it to your world's Assets/WebRoot/index.html for you. After a moment the Inspector shows the title Coords HUD and a list of settings. If nothing happens, click Refresh from server.
  4. Save the scene. Press Ctrl + S (Windows / Linux) or Cmd + S (Mac). Do this every time you add or remove a snippet. Closing Unity without saving is the main way extra copies of the snippet end up in index.html.
  5. Change the settings in the Inspector if you like. They're all listed under Settings.
  6. Upload your world the same way you always do, then join it in Altspace.

2b. Add it on the website

  1. Open your world for editing on altvr.app and go to the Snippets section.
  2. Find Coords HUD. Set the list to show All snippets, then search for Coords HUD (or scroll to it) and open it.
  3. Copy it. Click Copy & open index.html. This copies the snippet's code and opens your world's HTML (or copy the full snippet code below).
  4. Paste it in the right place. If your HTML has these two lines, paste between them: 
    <!-- snippet section -->
   paste here
<!-- end snippet section -->
    If it doesn't have them, paste it just before </body>.
  5. Change the settings by editing the values in quotes in the pasted code, for example decimals="0".
  6. Save, then join your world.

Keep the code tidy. Every value needs quotes around it (decimals="2", not decimals=2), and a & in any link must be written as &amp;. Unity reads this part strictly, and one mistake can break the whole snippet section.

The full snippet code

This is everything the snippet adds, with every setting at its default. Click the code to copy it.

Full snippet code
<!-- snippet section -->
<bs-snippet name="coords" title="Coords HUD" single="true"
  description="Shows where you're standing (X Y Z) and which way you face, in a corner of your view. Only you see yours."
  script="https://coords-hud.firer.at/snippet.js"
  corner=""
  desktop-corner="top-left"
  vr-corner="bottom-left"
  decimals="3"
  text-color="#ffffff"
  text-opacity="1"
  background-color="#000000"
  background-opacity="0.5"
  scale="1"
  vr-scale="1.25"
  north="+z"
  angle="false"
  refresh="0.1"
  vr-edge="0.2 0.15"
  desktop-edge="auto"
  margin="0.012"
  show-vr="true"
  show-desktop="true"
  toggle-key="F3"
  hidden="false"
  bundle-base="">
</bs-snippet>
<!-- end snippet section -->

Settings

All optional. An empty or missing setting uses the default.

SettingDefaultWhat it does
corner(empty)One corner for everyone: top-left, top-right, bottom-left or bottom-right. Empty uses the two below.
desktop-cornertop-leftThe corner on PC.
vr-cornerbottom-leftThe corner in VR.
decimals3Digits after the point: 0 for whole numbers, up to 6.
text-color#ffffffThe text's colour, like #ff8800.
text-opacity1From 0 (invisible) to 1 (solid).
background-color#000000The colour of the backdrop behind the text.
background-opacity0.5From 0 (no backdrop) to 1 (solid).
scale1Size of the HUD.
vr-scale1.25Extra size in VR, on top of scale.
north+zWhich world axis is North: +z, -z, +x or -x. East is a quarter turn clockwise from it, seen from above (with +z, East is +x).
anglefalsetrue also shows the compass heading in degrees.
refresh0.1Seconds between updates. 0 updates every frame.
vr-edge0.2 0.15VR: how far the HUD's outer edges are from the middle of your view, across and up, in metres at 50 cm away.
desktop-edgeautoPC: the same, or auto for the window's corner. Set it if the HUD sits wrong in your window.
margin0.012PC, with auto: the gap to the window's edges.
show-vrtruefalse: no HUD in VR.
show-desktoptruefalse: no HUD on PC.
toggle-keyF3The key that shows and hides the HUD on PC, or none.
hiddenfalsetrue starts with the HUD hidden (the toggle key shows it).
bundle-base(empty)A folder URL to load the HUD's bundles from instead of this site.

Good to know

  • The HUD is drawn 50 cm in front of your eyes, so a wall closer than that hides it.
  • Nobody else sees your HUD, and it isn't in anyone else's view of you.
